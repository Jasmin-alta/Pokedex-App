# 📱 Pokédex App

A Pokémon Pokédex application built with **React Native, Expo, and TypeScript**. This project was created as a hands-on learning experience to explore mobile app development, API integration, and navigation between screens.

## ✨ Features

- **Pokémon Browsing:** Displays Pokémon names, images, and types.
- **Pokémon Details:** Includes a separate details screen for exploring Pokémon information.
- **API Integration:** Retrieves Pokémon data from the PokéAPI.
- **Type-Based Styling:** Uses different colors to visually distinguish Pokémon types.
- **Mobile-Friendly Interface:** Built with React Native components for a mobile app experience.

## 🛠️ Technologies Used

- **React Native** — Building the mobile user interface
- **Expo** — Developing and testing the application
- **TypeScript** — Defining data structures and improving code reliability
- **Expo Router** — Navigating between screens
- **PokéAPI** — Retrieving Pokémon data

## 🚀 Getting Started

To run this project locally:

**1. Clone the repository**

```bash
git clone https://github.com/Jasmin-alta/Pokedex-App.git
```

**2. Navigate to the project folder**

```bash
cd Pokedex-App
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npx expo start
```

Follow the instructions in your terminal to open the app using Expo Go, a simulator, or a supported web browser.
